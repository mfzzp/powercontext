复习接力站

解决"隔几天回来，不知道从哪里不会"的学习痛点

解决的问题

学习者经常遇到这样的情况：隔几天回来复习，却想不起哪些知识点没弄懂、下一步应该从哪里继续。

复习接力站提供完整的学习接力流程：输入存档码 → 选择主题 → 查看题目与答案 → 自评掌握程度 → 系统自动记录薄弱点 → 下次继续时智能推荐下一题。

核心功能

匿名存档

输入存档码即可保存进度，不同存档码完全隔离，无需注册登录。

原创题库

Python、Git、数据库三个主题，每主题 5 题（共 15 题），含知识点和参考答案。

严格自评

不会(0)、模糊(1)、掌握(2)；拒绝布尔值、字符串、浮点数及超界值。

智能推荐

优先薄弱题 → 模糊题 → 未练题 → 已掌握题，同级按 ID 排序。

PowerContext 持久化

真实调用 PowerContext SQLite 后端，关闭服务重启后进度完整保持。

幂等提交

同一 request_id + 相同数据不新增；不同数据返回 409 冲突。

技术栈

Python 3.12 aiohttp 3.14 PowerContext (SQLite) HTML / CSS / JS pytest 9

后端 Python 3.12 + aiohttp，前后端同一进程提供服务。不需要外部模型 API Key，不依赖 seekdb。PowerContext 固定版本 9db17534。

本地体验步骤

本应用为有状态本地服务，需按以下步骤在本地启动后体验。本展示网站不提供后端 API。 
# 1. 克隆仓库并切换到开发分支
git clone https://github.com/mfzzp/powercontext.git
cd powercontext
git checkout 2026-competition-qoder
cd qoder

# 2. 安装依赖（Python 3.12+）
pip install -r requirements.txt

# 3. 启动服务（默认 127.0.0.1:8080）
python -m app.main

# 4. 浏览器打开 http://127.0.0.1:8080

# 5. 运行自动化测试（可选）
python -m pytest tests/test_app.py -v

启动后输入任意存档码（如 learner-001）即可开始复习。数据保存在 qoder/data/ 目录，删除该目录可重置。

使用流程

  1. 打开 http://127.0.0.1:8080，输入存档码，点击"进入"
  2. 选择主题（Python / Git / 数据库），进入题目
  3. 思考后点击"查看参考答案"，对比自己的理解
  4. 给自己打分：不会(0) / 模糊(1) / 掌握(2)
  5. 系统通过 PowerContext 自动保存，返回真实 citation
  6. 点击"继续复习"查看薄弱点、掌握数量和推荐下一题
  7. 关闭服务后重新启动，输入相同存档码即可继续

PowerContext 使用方式

每个存档码对应独立的 PowerContext scope，使用稳定 idempotency_key（review-station/{archive_code}）。

  • 每次自评通过 memory.remember() 写入，kind 为 review-practice
  • 查询进度通过 memory.list() + memory.get() 精确回读原始记录
  • 返回的 citation 包含 entry_id 和 entry_version_id
  • 审计日志记录在 data/powercontext-audit.jsonl
