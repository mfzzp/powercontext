## 目标与核心流程

开发一个适合学习者使用的小型 Web 应用，解决“隔几天回来，不知道上次哪里不会”的问题。实现：输入匿名存档码 → 选择主题 → 查看问题 → 展示参考答案 → 自评“不会/模糊/掌握” → 保存进度 → 返回薄弱点 → 关闭服务重启后继续。

## 功能要求

1. 原创题库至少包含 Python、Git、数据库三个主题，每主题至少 4 题。每题具有稳定 ID、问题、参考答案、知识点。禁止题库依赖作者机器上没有交付的文件。无需在线模型，不需要外部数据。
2. 自评分只接受整数 0、1、2，分别为不会、模糊、掌握；拒绝布尔值、字符串、浮点数及超界值。主题和题目 ID 必须有效。
3. 每个匿名存档码对应独立的 PowerContext scope，使用稳定 idempotency_key。记录包含请求 ID、题目 ID、自评分、练习序号和时间；每次成功练习通过真实 memory.remember 持久化，不能用本地 JSON 或进程内字典代替。
4. 从 memory.list/get 读取练习记录，对每题采用最新有效自评。优先推荐最近自评为 0 的题，再为 1 的题，再是从未练过的题，再是已掌握题；同级按稳定题目 ID 排序。返回推荐原因和对应的实际练习引用；未练过的题不能伪造历史引用。
5. 提供“继续复习”页，展示最近练习、薄弱知识点、已掌握数量和下一题。掌握率统计基于不同题目的最新自评，不把同一题反复提交计为多个已掌握知识点。
6. 同一请求 ID、同一数据重试应幂等；同 ID 不同数据拒绝。单进程写者下并发提交不会丢失或重复记录。每条记忆控制在 SDK 允许大小之内，所有用户输入校验。
7. 跨用户隔离，重启服务保持所有学习进度。提供明确的重置方法（例如新存档码），不要默认删除用户目录。
8. 前端中文，简洁清晰，适配桌面与手机，包含首次使用说明、空状态、保存失败提示。保存失败不得显示“已保存”。记忆暂不可读时返回错误，不得默默回退成空记录。

## 工程实现

- 采用 Python 3.12 的轻量后端加 HTML/CSS/JS，技术细节由你决定。不要为了演示强制引入模型、Embedding 或 seekdb。
- PowerContext 固定源码提交见 README，使用其 SQLite 后端。将用户数据置于可配置的 data/，保留真实精确 MemoryCitation。记录最小必要的技术使用日志，包括操作类型、scope、请求 ID 和 citation，不记录密钥。
- 依赖、模型需求（本方案没有模型）、安装步骤、启动命令、端口、配置、重置和已知限制写入 RUN.md。前后端可以同端口提供服务，简化跨域问题。
- 自动测试覆盖严格参数、真实 Memory 保存/读取、重启、最新自评更新、推荐排序、隔离、重复提交及失败不虚报成功。不要 mock 掉所有 PowerContext 使用后宣称接入验证通过。
- 交付至少一组实际运行命令和日志，记录退出码与对应版本。遇到权限或依赖限制如实标注，未执行不得写成通过。
